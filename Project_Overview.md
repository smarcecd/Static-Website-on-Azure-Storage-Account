# Project Overview – Deploy a Static Website on Azure Storage Account

## 📌 Purpose of This Lab
This project demonstrates how to deploy a fully functional static website using **Azure Storage Account Static Website Hosting**. It is designed as a hands‑on lab for cloud learners, Azure administrators, and engineers who want to understand lightweight, serverless web hosting on Azure.

By completing this lab, you will learn how to:
- Create and configure an Azure Storage Account
- Enable static website hosting
- Upload and manage website assets in the `$web` container
- Access the live website via the Azure‑generated endpoint
- Understand the architecture behind Azure Static Website Hosting

---

## 🧱 Architecture Summary
Azure Static Website Hosting uses **Azure Blob Storage** to serve static content (HTML, CSS, JS, images) directly to users over HTTPS. When static hosting is enabled, Azure automatically creates a special container named `$web` and exposes a **public endpoint** for the site.

### Core Components
- **Azure Storage Account**  
  Stores all website files and provides the hosting capability.
- **$web Container**  
  Special blob container where static site assets are stored.
- **Static Website Endpoint**  
  Public URL automatically generated by Azure.
- **Azure CDN (Optional)**  
  Can be integrated for global performance optimization.
- **Custom Domain (Optional)**  
  Allows mapping your own domain to the static site.

---

## 🌐 How the Static Website Works
1. The user enters the website URL (Azure endpoint or custom domain).
2. Azure Storage retrieves the requested file from the `$web` container.
3. The file is served directly to the browser over HTTPS.
4. No servers, VMs, or backend logic are required.

This architecture is ideal for:
- Portfolios  
- Documentation sites  
- Marketing landing pages  
- Static blogs (Hugo, Jekyll, etc.)
